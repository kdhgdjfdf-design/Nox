# ShadowBox Nox — النسخة التجريبية

هذه النسخة موجودة على الفرع `feature/local-smart-coach` للاختبار فقط. لا تدمجها في `main` قبل مراجعة النتائج والموافقة عليها.

## تشغيل المعاينة

### StackBlitz
افتح:
https://stackblitz.com/github/kdhgdjfdf-design/Nox/tree/feature/local-smart-coach

المشروع يحتوي على إعدادات Vite وStackBlitz لتشغيل صفحة التطبيق عبر `npm run dev`. انتظر تثبيت الحزم ثم افتح Preview. إذا ظهر الكود فقط، افتح لوحة Preview أو شغّل الأمر `npm run dev` من الطرفية.

### تشغيل محليًا
يتطلب Node.js:
```bash
npm install
npm run dev
```

## ما الذي تختبره؟

1. افتح التطبيق واضغط للدخول، وتأكد أن الشاشة الرئيسية تظهر.
2. افتح **المدرّب الذكي** وجرّب الأسئلة السريعة: مراجعة الجلسة، كومبو للمبتدئ، دقة إصابة الهدف، والدفاع الأساسي.
3. افتح التدريب واسمح للمتصفح باستخدام الكاميرا بعد التأكد من عنوان المعاينة.
4. جرّب حركات خفيفة وبطيئة نسبيًا ضمن مساحة خالية، ثم أنهِ الجولة.
5. راجع نتيجة الجولة ومؤشرات وضعية الحراسة والميل. قد لا تظهر مؤشرات الوضعية إذا لم تجمع الكاميرا عينات واضحة كافية.
6. اختبر العربية والإنجليزية إن كان تبديل اللغة متاحًا.

## حدود مهمة

- المدرب محلي قائم على قواعد ونصوص داخل التطبيق؛ لا يحتاج مفتاح API.
- الفيديو لا يُرفع إلى خادم بحسب تصميم هذا الفرع. تُحمّل مكتبة MediaPipe ونموذج تقدير الوضعية من مصادرها الخارجية، وتتم معالجة إطارات الكاميرا داخل المتصفح.
- مؤشرات انخفاض اليدين وميل الجذع تقديرية وليست تقييمًا رياضيًا احترافيًا أو طبيًا.
- الاختبارات البرمجية لا تعني أن الكاميرا اختُبرت فعليًا على كل هاتف. يلزم اختبارها في متصفح الهاتف.

## حدود التغييرات

- كل التعديلات هنا تجريبية على هذا الفرع.
- لا تغيّر إعدادات النشر ولا تدمج إلى `main` قبل موافقة المستخدم.
- المستودع المنفصل `shadowbox` خارج نطاق هذا الاختبار ويجب أن يبقى دون تغيير.
